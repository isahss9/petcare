PetCare

Aplicativo de gerenciamento de pets e organização de cuidados.

Flutter · Dart · Firebase

1. Visão geral

O PetCare é um projeto escolar desenvolvido em Flutter e Dart para apoiar o cadastro de animais de estimação e a organização de seus cuidados, incluindo vacinas, consultas veterinárias e medicamentos.

Importante: consulte o código atual para confirmar o comportamento de cada funcionalidade antes de alterar ou ampliar o sistema.

2. Tecnologias

  • Flutter/Dart: interface e lógica do aplicativo.
  • Firebase Authentication: autenticação de usuários.
  • Cloud Firestore: banco de dados de documentos.
  • Git/GitHub: controle de versão e hospedagem do repositório.
  • HTML/CSS: esta documentação técnica.

3. Arquitetura do código

O código é organizado por responsabilidade:

models/
Modelos que representam pets e registros de cuidados.
screens/
Telas de autenticação, navegação, agenda, pets e perfil.
widgets/
Componentes visuais reutilizáveis, como cartões de pets.
services/
Serviços de integração, incluindo autenticação.
repositories/
Abstração e acesso aos dados, incluindo implementações Firestore.
theme/
Configuração visual centralizada em app_theme.dart.

4. Modelo de dados

A organização lógica sugerida para separar os dados de cada usuário é:

users/{userId}
  pets/{petId}
    careRecords/{careRecordId}

Os pets representam os animais cadastrados. Os registros de cuidados representam eventos como vacina, consulta veterinária ou medicamento.

Confirme os nomes dos campos e os caminhos usados no código dos repositórios antes de modificar regras ou dados existentes.

5. Como executar

  1. Instale Flutter SDK e configure um dispositivo ou emulador.
  2. Abra um terminal na raiz do projeto.
  3. Execute flutter pub get.
  4. Confirme a configuração Firebase em lib/firebase_options.dart.
  5. Execute flutter analyze para analisar o código.
  6. Execute flutter run para iniciar o aplicativo.
flutter pub get
flutter analyze
flutter run

6. Segurança

  • Ative os provedores necessários no Firebase Authentication.
  • Configure regras do Firestore que exijam usuário autenticado.
  • Restrinja a leitura e a escrita aos documentos pertencentes ao usuário autenticado.
  • Não utilize regras públicas de leitura/escrita em um aplicativo real.
  • Não publique senhas, chaves privadas ou credenciais de serviço no repositório.

7. Checklist de validação

  • Cadastro e login funcionam com dados válidos.
  • Logout encerra a sessão e direciona à tela correta.
  • O CRUD de pets persiste os dados.
  • Os registros de cuidados podem ser criados e consultados.
  • Os botões do perfil têm ações claras.
  • A análise estática termina sem problemas.
